# Provisionamento Automatizado de Servidor Web

## Descrição

Neste projeto, será desenvolvido um script para automatizar o provisionamento e a configuração de um servidor Web em ambiente Linux.

Um servidor Web é responsável por receber, processar e responder às solicitações realizadas pelos clientes por meio dos protocolos HTTP/HTTPS, permitindo o acesso e a disponibilização de páginas e aplicações na Internet.

O objetivo é simplificar a implantação da infraestrutura, automatizando tarefas que normalmente seriam executadas manualmente, garantindo mais agilidade, padronização e facilidade na configuração de novos ambientes.

## Objetivos

- Automatizar a instalação e configuração do servidor Web.
- Reduzir a necessidade de intervenções manuais.
- Padronizar o processo de provisionamento.
- Facilitar a reprodução da infraestrutura em novas máquinas.
- Disponibilizar o script para reutilização e versionamento no GitHub.

## Tecnologias utilizadas

- Linux
- Shell Script (Bash)
- Apache ou Nginx
- Git e GitHub

## Resultado esperado

Ao executar o script, o ambiente deverá ser configurado automaticamente, deixando o servidor Web preparado para hospedar e disponibilizar páginas e aplicações.
